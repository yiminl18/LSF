## Available Actions

### action="generate"
Append ONE rule to the accumulated pool. Required field: `rule` = JSON string of
{{"rule_text": ..., "evidence_basis": ..., "retrieval_spec": {{...}}, "answer_hint_pattern": optional}}.

`retrieval_spec` MUST contain ONLY these fields (extras like `pattern`, `page_constraint` will be silently dropped):
{{
  "mode": "after"|"before"|"around"|"between"|"page"|"regex",
  "anchor": "literal text to locate; for mode=regex this IS the regex pattern" | null,
  "anchor_b": "second anchor for between mode" | null,
  "page_idx": page_number (positive int) | null,
  "max_chars": integer (extraction window),
  "boundary_context_chars": integer (default 0)
}}
For mode=regex, put the regex into `anchor` — there is NO separate `pattern` field.
For mode=page, set `page_idx` to a positive integer (NOT page_constraint).

### action="tool" (diagnostics — does NOT add a rule)
- batch_apply_rule(rule_spec, answer_hint_pattern?): try a candidate against the remaining docs
  before committing it via `generate`. Returns coverage, per-doc preview, anchor_universality,
  optional answer_present_count + hint_extraction_warning. No LLM cost.
- find_section(doc_id, keyword, max_chars?): inspect section heading + body preview. `max_chars`
  is optional (default 1500, capped at 4000). TOC lines show `[Nc]` section body size —
  pass `max_chars=N` to fetch the full section. No LLM cost. Capped at 4 consecutive calls.
- get_section(doc_id, section_id, max_chars?, include_tables?): PREFERRED navigation —
  fetch an entire section subtree body by its TOC `[id=K]`. Default max_chars=4000, cap 6000.
  Returns body + child_section_ids (for drill-down) + table_ids_in_body. No LLM cost.
- get_page(doc_id, page_idx, labels?, max_chars?): return all entries on a page, optionally
  filtered by labels (e.g. ["text","table"]). Useful for cover-page extraction. No LLM cost.
- apply_rule(rule_spec, doc_id): single-doc probe. No LLM cost.

## Strategy

- Use batch_apply_rule liberally to test candidates BEFORE generate (because generate is
  irreversible). When a candidate looks good, immediately generate it.
- Aim to add coverage: pick a rule that succeeds on as many of the remaining documents as
  possible while complementing the rules already selected.
- Prefer structural anchors (section headings, page indices) over literal company names or
  filing years, so the rule generalizes across the corpus.
- If the remaining docs are heterogeneous, target a coherent subset rather than an
  over-broad fallback.
