# Rules and Results Folder Structure

All generated rule files live under `rules/`. The structure is organized by dataset, generation strategy, model, and refinement stage.

```
rules/
├── financebench_single_cluster/       # Single-doc queries: one document per inference call
│   ├── llm/                           # Rules generated by a non-agentic LLM (single call)
│   │   └── gpt54/                     # Model: GPT-5.4 (Azure)
│   │       ├── one_shot/              # Raw rules from a single LLM call (rule_gen_llm_coarse.py)
│   │       │   └── <question_slug>_10_llm/   # 10 sampled docs used; many rules per question
│   │       └── refine/                # one_shot rules pruned by rule_refine.py to reduce cost
│   │           └── <question_slug>_10_refined/  # subset of one_shot rules, maintaining accuracy
│   │
│   └── agent/                         # Rules generated by an iterative agent loop
│       ├── gpt54/                     # Agent powered by GPT-5.4 (src/rule_gen_agent.py)
│       │   ├── raw/                   # Rules as written by the agent, before any pruning
│       │   │   └── <question_slug>_10_llm/   # 1–6 rules per question
│       │   └── refined/               # raw rules further pruned by rule_refine.py
│       │       └── <question_slug>_10/       # 1–4 rules per question
│       └── opus47/                    # Agent powered by Claude Opus 4.7 (src/rule_gen_agent_claude.py)
│           ├── raw/                   # Rules as written by the agent, before any pruning
│           │   └── <question_slug>/           # 1–2 rules per question
│           └── refined/               # (empty — refine step not yet run for Opus 4.7)
│
└── financebench_multi_clusters/       # Mix-doc queries: multiple document types per inference call
    ├── llm/                           # Rules generated by a non-agentic LLM (single call)
    │   └── gpt54/                     # Model: GPT-5.4 (Azure)
    │       ├── one_shot/              # Raw rules from a single LLM call (rule_gen_llm_coarse.py)
    │       │   └── <question_slug>_18_llm/   # 18 sampled docs used; many rules per question
    │       └── refine/                # (empty — refine step not yet run for mix-doc)
    │
    └── agent/                         # Rules generated by an iterative agent loop
        ├── gpt54/                     # Agent powered by GPT-5.4 (src/rule_gen_agent.py)
        │   ├── raw/                   # Rules as written by the agent, before any pruning
        │   │   └── <question_slug>_18_llm/   # 1–4 rules per question
        │   └── refined/               # (empty — refine step not yet run for mix-doc)
        └── opus47/                    # Agent powered by Claude Opus 4.7 (src/rule_gen_agent_claude.py)
            ├── raw/                   # Rules as written by the agent, before any pruning
            │   └── <question_slug>/           # 1–2 rules per question
            └── refined/               # (empty — refine step not yet run for mix-doc)
```

## Results Folder Structure

All evaluation outputs live under `results/`, mirroring the same `financebench_single_cluster / financebench_multi_clusters` hierarchy as `rules/`. Within each leaf folder (e.g. `one_shot/`, `raw/`, `refined/`) the following subfolders may appear:

| Subfolder | Contents | Source script |
|---|---|---|
| `rule_gen/` | Rule generation metadata JSON per question | `rule_gen_llm_coarse.py` / `rule_gen_agent.py` / `rule_gen_agent_claude.py` |
| `rule_run_individual/` | Per-rule span-retrieval + LLM answer outputs | `src/rule_apply_individual.py` |
| `rule_run_merge/` | Merged-rule span-retrieval + LLM answer outputs (sampled docs) | `src/rule_apply_merge.py` |
| `rule_run_merge_unsampled/` | Merged-rule span-retrieval + LLM answer outputs (unsampled docs) | `src/rule_apply_merge.py` |
| `rule_refine/` | Rule pruning trace and selected-rule metadata | `src/rule_refine.py` |
| `eval_individual/` | Accuracy + cost eval of individual rules | `test/run_eval_individual.py` |
| `eval_merge/` | Accuracy + cost eval of merged rules (sampled + unsampled) | `test/run_eval_merge_*.py` |
| `log/` | Agent run logs (stdout/stderr per question) | `test/run_task_prompt_all.py` / `src/rule_gen_agent.py` |
| `pipeline_summary.json` | End-to-end summary: rules generated, accuracy, cost per question | `test/rule_end_to_end.py` |
| `perf_summary.json` | Aggregated performance table across all questions | generated separately |

## Key Concepts

| Term | Meaning |
|---|---|
| `single_cluster` | Each query is evaluated against one document at a time |
| `multi_clusters` | Each query spans multiple document types in a single call (mix-doc) |
| `llm` | Rules generated by a single LLM call with no tool use or iteration |
| `agent` | Rules generated by an iterative agent that uses tools (e.g., `test_rule`, `test_union`) to refine rules |
| `one_shot` | No post-processing; rules are exactly as produced by the LLM |
| `refine` | Rules pruned by `src/rule_refine.py` to remove redundant rules while preserving accuracy |
| `raw` | Agent rules before any external pruning step |
| `refined` | Agent rules after `src/rule_refine.py` pruning |
| `_10_llm` | Slug suffix indicating 10 sampled docs were used during rule generation |
| `_18_llm` | Slug suffix indicating 18 sampled docs were used during rule generation |
| `_10_refined` | Slug suffix for LLM one-shot rules after the refine pruning step |

| Folder | Script |
|---|---|
| `financebench_single_cluster/llm/gpt54/one_shot` | `src/rule_gen_llm_coarse.py` via `test/run_rule_gen_llm_all.py` |
| `financebench_single_cluster/llm/gpt54/refine` | `src/rule_refine.py` via `test/run_rule_refine_all.py` |
| `financebench_single_cluster/agent/gpt54/raw` | `src/rule_gen_agent.py` via `test/rule_end_to_end.py` |
| `financebench_single_cluster/agent/gpt54/refined` | `src/rule_refine.py` (called inside `test/rule_end_to_end.py`) |
| `financebench_single_cluster/agent/opus47/raw` | `src/rule_gen_agent_claude.py` via `test/run_task_prompt_all.py` |
| `financebench_multi_clusters/llm/gpt54/one_shot` | `src/rule_gen_llm_coarse.py` (mix-doc run) |
| `financebench_multi_clusters/agent/gpt54/raw` | `src/rule_gen_agent.py` (mix-doc run) |
| `financebench_multi_clusters/agent/opus47/raw` | `src/rule_gen_agent_claude.py` (mix-doc run) |
