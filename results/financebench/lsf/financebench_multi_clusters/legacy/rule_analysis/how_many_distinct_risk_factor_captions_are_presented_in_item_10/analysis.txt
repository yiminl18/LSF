===========================================================================
ROOT CAUSE 1 — Ground truth convention: "not disclosed" ≠ "no risk factors"
===========================================================================
The ground truth for all 10 sampled docs is "Not disclosed". This does NOT mean
the documents lack an Item 1A section — most 10-K filings clearly have one with
20-40 named risk factor captions. "Not disclosed" means the document does not
explicitly state a summary count of risk factors. The correct answer requires
recognizing that no explicit count is provided and returning "not disclosed",
NOT counting the captions from the retrieved text.

The rules successfully retrieve the Item 1A section (8-9/10 docs). The LLM
then counts the risk factor headers it sees and returns a number (20-31). This
is technically correct as a count, but wrong per the ground truth convention.

===========================================================================
ROOT CAUSE 2 — Rules retrieve risk factor captions, prompting the LLM to count
===========================================================================
Rules like rule_risk_factor_caption_bolditalic_under_item_1a,
rule_risk_factor_category_bold_text, rule_item_1a_and_next_five_pages etc.
all fire on 7-8/10 docs and retrieve the actual bold/italic risk factor headings.
When the LLM is given a passage containing these captions, it naturally counts
them rather than checking whether the document itself states a count.

The two correct predictions (INTEL earnings release, FOOTLOCKER 10-Q) succeed
because those docs either have no Item 1A or Item 1A says "refer to our annual
report" — rules retrieve no captions, and the LLM correctly returns "not
disclosed".

===========================================================================
ROOT CAUSE 3 — No rule checks for explicit count disclosure
===========================================================================
There is no rule that checks whether the document contains a sentence like
"We have X risk factors" or a numbered list header. Without such a rule,
the LLM is shown the risk factor text and defaults to counting.

===========================================================================
BAD RULES
===========================================================================
1. rule_risk_factor_caption_bolditalic_under_item_1a,
   rule_risk_factor_caption_sentence_case_under_item_1a,
   rule_risk_factor_caption_long_bold_under_item_1a,
   rule_risk_factor_caption_h4_under_item_1a,
   rule_risk_factor_caption_excluding_item_header
   - All fire on 7-8/10 docs and retrieve individual risk factor headings.
     Providing these to the LLM causes it to count them.
   - Fix: these rules are only useful if the task is to count captions. For
     a "not disclosed" ground truth, they are harmful. Consider removing them
     or wrapping in a check: only return captions if the document itself states
     a summary count.

2. rule_item_1a_and_next_five_pages, rule_item_1a_page_from_toc,
   rule_risk_factor_pages_from_path
   - Retrieve entire Item 1A pages (8/10 hits). Giving the LLM a full page
     of risk factor content makes it count rather than detect "not disclosed".

===========================================================================
FIX DIRECTION
===========================================================================
- Add a rule that specifically looks for an explicit numeric count of risk
  factors (e.g., "We face X material risk factors"). If found, return that
  span. If not found, return an empty list so the LLM defaults to "not
  disclosed".
- Remove rules that return individual risk factor captions — they cause
  counting behavior.
- Keep only rules that find the Item 1A header and the first paragraph
  (which may or may not state a count), not all the individual captions.
- Note: this question is fundamentally a "detect absence" task, not a
  "retrieve and read" task. Rules should be designed accordingly.
