  Refinement effects, query by query:
    - Cost cuts are large and consistent on all queries (3x to 50x reductions in
      sCost). The biggest absolute saves: total revenue (0.867 -> 0.015, ~56x),
      total assets (0.250 -> 0.031, ~8x), net income (0.211 -> 0.113, ~2x).
    - Sampled accuracy is preserved on 9/10 queries; total assets drops 1.00->0.90.
    - Unsampled drops concentrate on four queries:
        shares outstanding (0.98 -> 0.66, -0.32)
        long-term debt     (0.66 -> 0.46, -0.20)
        telephone number   (1.00 -> 0.82, -0.18)
        state of incorp    (0.98 -> 0.88, -0.10)
        total revenue      (0.82 -> 0.70, -0.12)
      Refinement keeps the rules that pass the 10 sampled docs and prunes those
      that didn't fire there — but some pruned rules were the ones that
      generalized to unsampled cover-page layouts.
    - Trading symbols and address actually improve unsampled cost without losing
      accuracy after refinement, suggesting their pruned rules really were
      redundant on the sampled set.

Coverage / caveats:
  - LLM one-shot: 10/10 questions (latest run per question kept when duplicates exist).
  - Agent GPT-5.4: 10/10 latency; 7/10 token totals (3 runs logged 0 tokens). The 9
    GPT-5.4 agent rule_gen JSONs sit under agent/opus47/raw/rule_gen/ with model="gpt54"
    (folder reorg artifact); 1 lives under agent/gpt54/raw/rule_gen/.
  - Agent Opus 4.7: 4/10 questions have rule_gen JSONs (1× claude-opus-4-7,
    3× claude-opus-4-5); 1 of those logged 0 tokens / 0 calls and is excluded, so
    averages are over n=3. Token totals are not directly comparable to the GPT-5.4
    agent — the Opus runs only log the rule-gen agent's own tokens, while GPT-5.4
    totals include the judge.
  - Input tokens: LLM one-shot = the raw prompt over 10 sampled docs (single call).
    Agent totals sum across all rounds, so per-call input is much smaller than the
    headline figure.

Observation: the LLM one-shot path is by far the cheapest in tokens (~270k in / 7.5k
out per question, single call) and finishes in ~3.7 min. The GPT-5.4 agent uses ~10x
more input tokens and many short calls but completes in similar wall time. Opus 4.7
takes ~2.6x longer on average per question, with far higher LLM-call counts but
lower input-token totals where they were measured.
